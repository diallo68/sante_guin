## Accès aux Applications

### Application Web
- **Dossier :** `/web`
- **Démarrage :** `cd web && pnpm dev`
- **URL :** http://localhost:3000

### Application Mobile
- **Dossier :** `/mobile`
- **Démarrage :** `cd mobile && pnpm dev`
- **URL :** http://localhost:8081

## Technologies

- **Web :** Next.js 14, React 19, TypeScript, Tailwind CSS
- **Mobile :** Expo 54, React Native, TypeScript, NativeWind
