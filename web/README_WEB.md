# Guinée Santé Web - Application Web

## 🌐 Description
Version web responsive de l'application Guinée Santé pour tester et gérer la plateforme depuis un navigateur.

## 🚀 Démarrage Rapide

### Prérequis
- Node.js 18+ installé
- pnpm installé (`npm install -g pnpm`)

### Installation
```bash
cd web_guinee_sante
pnpm install
pnpm dev
```

### Accès
L'application sera disponible sur `http://localhost:3000`

## 📁 Structure du Projet
- `app/` - Pages et composants Next.js
- `app/auth/` - Pages d'authentification
- `app/doctors/` - Pages de recherche de médecins
- `app/pharmacies/` - Pages de recherche de pharmacies
- `app/messages/` - Pages de messagerie
- `app/admin/` - Pages d'administration
- `components/` - Composants réutilisables
- `public/` - Ressources statiques
